# Джарвис

Семейный ИИ-ассистент с **когнитивной памятью по образцу человеческой**.
«Сознание» — Claude Opus 5.5, «подсознание» памяти — Claude Haiku 5.5, память — пакет `cogmem`.

> Статус: готовы этапы 1–3 плана (каркас, память, стенд измерений) и основа этапов 4–6
> (подсознание, «сон», процедурная и проспективная память). Голос, устройства и ретранслятор
> для России — следующие этапы.

## Как устроена память

Память построена по научным моделям человеческой памяти (подробные ссылки — в коде модулей):

| Слой | Что хранит | Модуль |
|---|---|---|
| Сенсорный журнал | каждая реплика дословно, **только добавление** (защищено триггером БД) | `cogmem/episodes.py` |
| Эпизодическая | эпизоды разговоров + сводки день/неделя/месяц/год | `cogmem/episodes.py`, `consolidate/sleep.py` |
| Семантическая | факты с **двумя временами**: когда было верно и когда узнали; старое не стирается, а закрывается | `cogmem/facts.py` |
| Сущности-схемы | люди, места, вещи; прозвища у каждого свои («мама») | `cogmem/entities.py` |
| Процедурная | рецепты действий со счётчиком успехов | `cogmem/procedural.py` |
| Проспективная | напоминания и намерения | `cogmem/prospective.py` |
| Ядро | профиль собеседника, всегда в контексте; собирается из фактов, а не пишется ИИ | `cogmem/core.py` |

Процессы:

- **Запись** (каждая реплика, без ИИ): вектор смысла, оценка важности (эмоции, «запомни», рассказ о себе),
  деление на эпизоды по паузе и смене темы.
- **Вспоминание** (< 100 мс): поиск по смыслу + по словам + по графу связей (PageRank от упомянутых людей),
  активация ACT-R (частое и недавнее доступнее), фильтр по периоду («в прошлом месяце»), отбор в бюджет токенов.
- **Подсознание** (1 вызов Haiku на эпизод): «предсказать → сверить» — сохраняется только новое и изменившееся.
  Каждое предложение проходит **шлюз записи**: доказательства только из реплик, внешние тексты не переписывают
  знания, пароли и карты не хранятся.
- **Сон** (ночью): сводки, сверка фактов с оригиналом (против «дрейфа»), напоминания о днях рождения,
  пересборка профиля.
- **Переконсолидация**: модель отмечает, какие воспоминания пригодились — они укрепляются, связи между ними усиливаются.
- **Приватность в семье**: личное одного не видно другим — проверяется до поиска.

## Измерения

Стенд `evals/` — 200 дней синтетической «жизни семьи» на русском (2176 реплик), 31 вопрос по способностям
LongMemEval + приватность, включая перефразировки («На чём я езжу?» → «Моя машина — Peugeot») и ловушки
(кот соседа, чай жены).

| Модель смыслов | Точность | Перефразировки | Задержка p50 |
|---|---|---|---|
| multilingual-e5-large (по умолчанию) | **31/31 (100%)** | 10/10 | ~67 мс |
| paraphrase-multilingual-MiniLM-L12-v2 | 30/31 (96.8%) | 9/10 | ~15 мс |

```bash
python -m evals.run            # полный офлайн-прогон (без API, бесплатно)
python -m evals.run --live     # с Claude: подсознание + ответы + судья (нужен ключ, стоит денег)
```

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e '.[embeddings,telegram,dev]'
cp .env.example .env    # вписать ANTHROPIC_API_KEY и имена
jarvis                  # разговор в терминале; /память /профиль /почему F12 /сон /выход
python -m jarvis.channels.telegram   # бот в Telegram (только для людей из белого списка)
pytest -q               # тесты
```

На VPS: `cd deploy && docker compose up -d --build`. Вся память — в папке `data/` (её и бэкапить).

## Расходы

Ход разговора ≈ $0.02 на Opus 5.5 (постоянная часть запроса кэшируется), фоновая память на Haiku 5.5 —
меньше $1 в месяц. Жёсткий месячный лимит — `JARVIS_MONTHLY_BUDGET_USD`.
