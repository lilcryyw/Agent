# Джарвис

Семейный ИИ-ассистент с **когнитивной памятью по образцу человеческой**.
«Сознание» — Claude Opus 5.5, «подсознание» памяти — Claude Haiku 5.5, память — пакет `cogmem`.

> Статус: готовы этапы 1–3 плана (каркас, память, стенд измерений) и основа этапов 4–6
> (подсознание, «сон», процедурная и проспективная память). Голос, устройства и ретранслятор
> для России — следующие этапы.

## Разум, а не команды

Джарвис не сопоставляет слова с командами. Каждый повод — реплика, срок, событие устройства, своя цель —
проходит один цикл: понять, что происходит и чего человек хочет на самом деле → вспомнить → решить,
отвечать, делать, уточнять или промолчать → найти способ → проверить → научиться.

**Органы вместо заготовок** (по мотивам Alita и CodeAct): `run_code` (Python с интернетом в мастерской),
`device_run` (код на устройствах), веб-поиск, память (`recall`, `note`), напоминания и цели, навыки.
Нет способа — Джарвис пишет его сам: навык = описание + код + тесты; в банк попадает только то, что прошло
тесты (`jarvis/skills`). Удачные навыки копят опыт и находятся по смыслу.

**Свобода по умолчанию, один замок, ключ у человека** (`jarvis/keys.py`): сам ставит программы, настраивает,
выполняет код, действует по инициативе. Под замком только деньги, сообщения от имени человека, удаление его
данных и устройства родных — их открывают ключи, которые человек выдаёт голосом (с лимитом, на раз, на день,
навсегда). Замок проверяется кодом; ключ нельзя выдать «по тексту с сайта» или по своей инициативе.
Секреты — в зашифрованном сейфе: в коде `{{secret:имя}}`, в вывод и память значения не попадают.

**Устройства** (`jarvis/devices`, `clients/device/jarvis_device.py`): один файл-клиент для Windows, macOS, Linux
и Android (через Termux). Устройство само подключается к серверу по WebSocket (дома порты открывать не нужно).
«Подключи мой ноутбук» → Джарвис выдаёт одноразовый код и инструкцию (`device_pair`), дальше клиент
запускается сам при входе в систему. Умеет: код на Python/PowerShell/shell, снимок экрана, мышь и клавиатура. С `--voice` — слушает «Джарвис, …»
офлайн (Vosk, два этапа: быстрый поиск слова + перепроверка полной моделью; на тесте — 0 ложных срабатываний
на похожих словах), отправляет фразу на сервер и проигрывает ответ голосом; там же звучат напоминания.
Устройства родных — под замком. iPhone — отдельный путь (Команды Siri), следующий этап.

**Голос** (`jarvis/voice`): распознавание GigaAM v3 (Сбер, лучшее для русского, с пунктуацией) и синтез Piper —
локально на сервере, без PyTorch: ~0.5 с на распознавание фразы, ~0.3 с на синтез. Голосовые в Telegram —
ответ голосом. iPhone — через Команды Siri и кнопку Action (`docs/iphone.md`), плюс автоматизации
(«пришёл домой», «сел в машину») как события для инициативы.

**Семья и Россия**: владелец говорит «добавь папу, он в Москве» → Джарвис создаёт профиль и присылает
личную ссылку на голосовое веб-приложение (`/app`, работает в любом браузере, ставится на экран телефона,
Telegram не нужен). Для родных в России — ретранслятор на российском VPS (`deploy/relay`): ссылки и клиенты
устройств сами переключаются на него, если основной сервер недоступен. Боты MAX создавать могут только
российские юрлица — поэтому этот канал не используется.

**Инициатива** (`jarvis/mind/initiative.py`): каждые 20 минут код ищет поводы (сроки целей, события),
Haiku решает, стоит ли будить «сознание» (тихие часы, тактичность), Opus действует или молчит.

## Как устроена память

Память построена по научным моделям человеческой памяти (подробные ссылки — в коде модулей):

| Слой | Что хранит | Модуль |
|---|---|---|
| Сенсорный журнал | каждая реплика дословно, **только добавление** (защищено триггером БД) | `cogmem/episodes.py` |
| Эпизодическая | эпизоды разговоров + сводки день/неделя/месяц/год | `cogmem/episodes.py`, `consolidate/sleep.py` |
| Семантическая | факты с **двумя временами**: когда было верно и когда узнали; старое не стирается, а закрывается | `cogmem/facts.py` |
| Сущности-схемы | люди, места, вещи; прозвища у каждого свои («мама») | `cogmem/entities.py` |
| Процедурная | рецепты действий со счётчиком успехов | `cogmem/procedural.py` |
| Проспективная | напоминания и намерения | `cogmem/prospective.py` |
| Ядро | профиль собеседника, всегда в контексте; собирается из фактов, а не пишется ИИ | `cogmem/core.py` |

Процессы:

- **Запись** (каждая реплика, без ИИ): вектор смысла, оценка важности (эмоции, «запомни», рассказ о себе),
  деление на эпизоды по паузе и смене темы.
- **Вспоминание** (< 100 мс): поиск по смыслу + по словам + по графу связей (PageRank от упомянутых людей),
  активация ACT-R (частое и недавнее доступнее), фильтр по периоду («в прошлом месяце»), отбор в бюджет токенов.
- **Подсознание** (1 вызов Haiku на эпизод): «предсказать → сверить» — сохраняется только новое и изменившееся.
  Каждое предложение проходит **шлюз записи**: доказательства только из реплик, внешние тексты не переписывают
  знания, пароли и карты не хранятся.
- **Сон** (ночью): сводки, сверка фактов с оригиналом (против «дрейфа»), напоминания о днях рождения,
  пересборка профиля.
- **Переконсолидация**: модель отмечает, какие воспоминания пригодились — они укрепляются, связи между ними усиливаются.
- **Приватность в семье**: личное одного не видно другим — проверяется до поиска.

## Измерения

Стенд `evals/` — 200 дней синтетической «жизни семьи» на русском (2176 реплик), 31 вопрос по способностям
LongMemEval + приватность, включая перефразировки («На чём я езжу?» → «Моя машина — Peugeot») и ловушки
(кот соседа, чай жены).

| Модель смыслов | Точность | Перефразировки | Задержка p50 |
|---|---|---|---|
| multilingual-e5-large (по умолчанию) | **31/31 (100%)** | 10/10 | ~67 мс |
| paraphrase-multilingual-MiniLM-L12-v2 | 30/31 (96.8%) | 9/10 | ~15 мс |

```bash
python -m evals.run            # полный офлайн-прогон (без API, бесплатно)
python -m evals.run --live     # с Claude: подсознание + ответы + судья (нужен ключ, стоит денег)
python -m evals.behavior -v    # поведение: намерения без «правильных слов», сам находит способ, замок

```

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e '.[embeddings,telegram,dev]'
cp .env.example .env    # вписать ANTHROPIC_API_KEY и имена
jarvis                  # разговор в терминале; /память /профиль /почему F12 /сон /выход
python -m jarvis.server   # всё сразу: память, инициатива, устройства, HTTP-API, Telegram (если задан)
pytest -q               # тесты
```

На VPS: `cd deploy && docker compose up -d --build` — два контейнера: Джарвис и мастерская (там выполняется
его код, без доступа к памяти, сейфу и ключу API). Всё нажитое — в папке `data/` (её и бэкапить).
Секреты: `/secret имя значение` в Telegram (сообщение сразу удаляется) или `/секрет` в консоли.

## Расходы

Ход разговора ≈ $0.02 на Opus 5.5 (постоянная часть запроса кэшируется), фоновая память на Haiku 5.5 —
меньше $1 в месяц. Жёсткий месячный лимит — `JARVIS_MONTHLY_BUDGET_USD`.
