# Мёртвый перегон

3D-игра для iPhone: вы машинист тепловоза 2ТЭ116 и ведёте поезд через бесконечную Россию во время зомби-апокалипсиса.

## Что есть в игре

- **Настоящее управление**: контроллер машиниста (позиции 0–15), реверсор (В / 0 / Н), кран машиниста №395 с положениями I–VI, давление в тормозной магистрали (ТМ), главных резервуарах (ГР) и тормозных цилиндрах (ТЦ). Боксование на мокрых рельсах, в листопад и снег — помогает песок. Кнопка бдительности РБ и система КЛУБ (ограничение 100 км/ч).
- **Бесконечный мир без повторов**: каждый участок строится из зерна мира. Деревни с избами, дачи, города с хрущёвками и девятиэтажками, промзоны с заводами и элеваторами, леса, поля, болота. Вокзалы, остановочные платформы, переезды, магазины («Продукты», аптека, хозтовары, автозапчасти, «Охота и рыбалка»), гаражи, АЗС, церкви, школы, больницы, отделы полиции, военные блокпосты, брошенные машины и вагоны. Названия станций генерируются. Сезоны меняются (лето, осень, зима), погода (ясно, дождь, туман, снег), день и ночь.
- **Зомби 8 видов**: ходок, путеец, бегун, толстяк, крикун (зовёт остальных), солдат в каске, обмороженный (зимой), громила.
- **Вылазки**: остановитесь у постройки — появится «Обыскать». Пока вы обыскиваете, зомби идут к вам, прикрывайтесь огнём.
- **Экономика, которая не ломается**: в каждом поселении свои цены; одинаковый товар там скупают всё дешевле, рынок восстанавливается со временем. Кроме бытовых вещей — ценности (самовар, гармонь, икона, «Зенит», медали) и уникальные находки (письма, дневники, карты), у каждой своя цена.
- **Улучшения поезда**: отвал-таран, бронелисты, пулемёт на крыше, дополнительные вагоны, цистерна, прожектор, капремонт дизеля.
- Оружие: ПМ, обрез ТОЗ, ПП-19 «Бизон», АК-74, СВД.

## Как установить на iPhone как приложение

Настоящее приложение из App Store требует Mac, Xcode и платный аккаунт разработчика Apple. Поэтому игра сделана как веб-приложение, которое ставится на экран «Домой» без всего этого: своя иконка, запуск на весь экран, работает без интернета после первого запуска.

1. В настройках репозитория на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `claude/zombie-train-game`, папка `/ (root)` → **Save**.
2. Через минуту игра будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
3. Откройте этот адрес в **Safari** на iPhone → кнопка «Поделиться» → **«На экран „Домой“»**.
4. Запускайте с иконки «Перегон». Держите телефон горизонтально.

Если репозиторий приватный, GitHub Pages доступен только на платном тарифе — тогда сделайте копию игры в отдельном публичном репозитории.

## Управление

1. **ПУСК** — запуск дизеля.
2. **Реверсор** в «В».
3. **Кран** в II — тормоза отпускаются, ждите, пока стрелка ТЦ упадёт к нулю.
4. **Контроллер** вверх — тяга. Торможение: кран в V, затем в III (перекрыша); VI — экстренное.
5. Касание по зомби — выстрел. Провести пальцем — повернуть камеру. «Вид» — из кабины.

На компьютере: W/S — контроллер, 1–6 — положения крана, пробел — РБ, H — тифон.

## Устройство

- `index.html` — интерфейс пульта.
- `js/world.js` — генерация мира по участкам 100 м, `js/models.js` — 3D-модели, `js/train.js` — физика поезда и пневматика, `js/zombies.js` — зомби, `js/audio.js` — синтез звука, `js/data.js` — предметы, лут, названия, `js/main.js` — игровой цикл.
- `vendor/three.module.min.js` — three.js 0.169.
- `assets/tex` — фото-текстуры с [Poly Haven](https://polyhaven.com) (CC0), уменьшены до 512 px.
- `sw.js` и `manifest.webmanifest` — установка на экран «Домой» и офлайн-режим.

Для локального запуска: `python3 -m http.server` в папке и открыть `http://localhost:8000`.
