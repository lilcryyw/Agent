# Приложение «Джарвис» для Android

Полное управление телефоном: Джарвис видит экран (дерево элементов через спец. возможности),
нажимает и печатает, выполняет команды shell, отвечает голосом, работает в фоне.

## Готовый APK
`jarvis.apk` в этой папке — собранный отладочный APK (debug). Сервер сам отдаёт его по адресу
`https://ВАШ-ДОМЕН/devices/jarvis.apk`, поэтому вручную ничего качать не нужно: скажи Джарвису
«подключи мой телефон» — он пришлёт ссылку и код.

## Установка
1. Открой ссылку на телефоне → разреши установку из этого источника → установи.
2. Открой «Джарвис» → впиши адрес (`wss://ВАШ-ДОМЕН/devices`) и код от Джарвиса → «Подключить».
3. Нажми «Включить управление» → в списке найди «Джарвис» → включи. Теперь он управляет телефоном.

Если телефон рядом с подключённым к Джарвису компьютером, он может установить и настроить всё сам
по ADB (попросит включить «Отладку по Wi-Fi» и продиктовать код сопряжения).

## Сборка из исходников
Нужен Android SDK (platform 34, build-tools 34). Затем:
```
cd clients/android
echo "sdk.dir=/путь/к/android-sdk" > local.properties
gradle assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk jarvis.apk
```

## Что внутри
- `JarvisAccessibility` — видит экран как дерево элементов, нажимает, печатает, листает (без root).
- `LinkService` — постоянная связь с сервером (тот же протокол, что у клиента на ПК), запуск при включении.
- `Actions` — выполняет run / screenshot / input / ui_tree по просьбе Джарвиса.
- `Speech` — проигрывает голос Джарвиса или синтез Android.

## Безопасность
Приложение подключается только к вашему серверу по его токену. Спец. возможности — мощное разрешение;
включайте, только если доверяете своему серверу. Действия на телефонах других членов семьи у Джарвиса
под замком.
