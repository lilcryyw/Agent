# Команды «Джарвис» на iPhone

Джарвис не может сам нажимать в приложениях iPhone, но он может прислать **кнопку**, а Команда
выполнит действие. Ниже — 11 Команд. Имена важны: Джарвис вызывает их по точному названию.

## Как создать Команду (один раз на каждую)
1. Открой приложение **Команды** → **+** (новая Команда).
2. Нажми на название сверху и введи **точно** имя из списка ниже (например `Джарвис: будильник`).
3. Нажми **Добавить действие** и найди нужное действие по названию из списка.
4. Вход Команды: включи **«Получать ввод из Быстрых команд»** (настройка Команды → «Тип ввода: Текст»).
   Так текст из кнопки Джарвиса попадает в Команду как «Ввод».
5. Сохрани (**Готово**). Кнопки в ответах Джарвиса сработают после этого.

Все Команды ниже берут **Ввод** (текст из кнопки). Если Ввод пуст — Команда просто делает действие по умолчанию.

## Список Команд

| Имя Команды | Что делает | Шаги |
|---|---|---|
| `Джарвис: будильник` | будильник | «Установить будильник» → время: **Ввод** |
| `Джарвис: таймер` | таймер | «Запустить таймер» → длительность: **Ввод** (минуты) |
| `Джарвис: напоминание` | напоминание | «Создать напоминание» → заголовок: **Ввод** |
| `Джарвис: событие` | событие в календарь | «Создать событие» → заголовок: **Ввод**, начало: спросить или сегодня |
| `Джарвис: заметка` | заметка | «Создать заметку» → текст: **Ввод** |
| `Джарвис: открыть сайт` | сайт | «Открыть URL» → **Ввод** (если нет http, добавь «https://» в начало) |
| `Джарвис: позвонить` | звонок | «Найти контакты» (имя = **Ввод**) → «Позвонить». iOS может спросить подтверждение |
| `Джарвис: написать` | сообщение | Ввод делим: имя до двоеточия, текст после. «Найти контакты» → «Отправить сообщение». **Включи «Спрашивать перед запуском»** |
| `Джарвис: музыка` | музыка | «Воспроизвести музыку» (поиск по **Ввод**, если пусто — случайная) |
| `Джарвис: погода` | погода | «Получить текущую погоду» → «Показать результат» |
| `Джарвис: фокус` | режим фокуса | «Установить фокус» → on/off из **Ввод**. Названия режимов зависят от версии iOS — проверь |

## Важно
- **Сообщения и звонки от вашего имени** — всегда включай «Спрашивать перед запуском». Тогда iPhone
  покажет подтверждение, и без вашего «да» ничего не уйдёт. Это главная страховка.
- Нет точного действия в вашей версии iOS — пропусти Команду, Джарвис скажет, что не может.
- Команды не могут читать чужие приложения и нажимать внутри них. Это ограничение Apple, его не обойти без Mac.

## Как Джарвис выдаёт кнопку
Когда нужно, Джарвис вызывает инструмент `iphone_action` и вставляет в ответ кнопку. На iPhone она открывает
Команду со вводом. Например: «поставь будильник на 7:30» → кнопка «⏰ Поставить будильник» → Команда получает `07:30`.
