# Джарвис на iPhone

Apple не даёт сторонним программам управлять iPhone, поэтому Джарвис работает через встроенные
**Команды** (Shortcuts): голосом через Siri или кнопкой Action (iPhone 15 Pro и новее).

## 1. Получить токен
В Telegram напиши боту Джарвиса `/token`. Он пришлёт строку вида `jv_…` — это ключ твоего iPhone.
Никому её не показывай. Если потерял телефон — скажи Джарвису, токен отзовём.

## 2. Команда «Джарвис» (голос → ответ голосом)
Приложение «Команды» → «+» → назови команду **Джарвис**. Добавь действия по порядку:

1. **Диктовать текст** — язык: Русский; «Остановить прослушивание»: после паузы.
2. **Получить содержимое URL**
   - URL: `https://ВАШ-ДОМЕН/api/ask`
   - Метод: POST
   - Заголовки: `Authorization` = `Bearer jv_…` (твой токен), `X-Device` = `iphone`
   - Тело запроса: JSON, поле `text` = «Продиктованный текст»
3. **Получить значение словаря** — ключ `reply` из «Содержимое URL».
4. **Произнести текст** — «Значение словаря» (голос — любой русский).

Теперь: «Привет, Siri, Джарвис» — и говори. Или: Настройки → Кнопка действия → Команда → Джарвис.

> Распознавание речи здесь делает сам iPhone (быстро, бесплатно). Хочешь голос Джарвиса вместо голоса
> iPhone — вместо шагов 1–4: **Записать аудио** → **Получить содержимое URL** `…/api/voice?reply=audio`
> (POST, тело — «Файл», файл — запись) → **Воспроизвести звук**.

## 3. Автоматизации (Джарвис узнаёт о твоей жизни сам)
«Команды» → «Автоматизация» → «+». Для каждой — действие **Получить содержимое URL**:
POST `https://ВАШ-ДОМЕН/api/event`, те же заголовки, JSON `text` = описание события. Примеры:

| Когда | text |
|---|---|
| Прибытие домой | `Пришёл домой` |
| Уход из дома | `Ушёл из дома` |
| Будильник остановлен | `Проснулся` |
| Уровень заряда ниже 20% | `Батарея iPhone ниже 20%` |
| Подключение к CarPlay | `Сел в машину` |

Это не команды, а события: Джарвис сам решает, нужно ли что-то сделать («ты ушёл, а ПК не выключен — выключить?»).
Включи «Выполнять сразу», чтобы iPhone не спрашивал подтверждение.

## Что недоступно на iPhone (ограничения Apple)
Тихая установка приложений, управление экраном, чтение чужих приложений. Полное управление экраном
возможно только через Mac с WebDriverAgent и платным аккаунтом разработчика Apple — это отдельный этап.
