# Сервер Джарвиса на Android-телефоне (бесплатно)

Подходит, если нет денег на сервер и нет компьютера. Телефон должен быть **на зарядке и в Wi‑Fi** —
пока он включён, Джарвис работает для всей семьи.

## Установка (один раз, ~20 минут)
1. Поставь **Termux** из F-Droid: https://f-droid.org/packages/com.termux/
   (версия из Google Play устарела и не подойдёт). По желанию — **Termux:Boot**
   (https://f-droid.org/packages/com.termux.boot/), тогда Джарвис сам запускается после перезагрузки.
2. Открой Termux и вставь:
   ```
   curl -fsSL https://raw.githubusercontent.com/lilcryyw/Agent/claude/jarvis-cogmem/deploy/termux/install.sh | bash
   ```
3. Когда спросит, вставь токен Hugging Face (`hf_…`). Ключи и настройки скрипт возьмёт сам
   из твоего приватного хранилища.
4. Первый запуск скачивает модели речи и смысла (~3 ГБ) — нужно 5–15 минут. В конце появится
   **ссылка для владельца** — открой её на iPhone, нажми «На экран Домой», потом 📞.

## Чтобы Android не выключал Джарвиса
- Настройки → Приложения → Termux → Батарея → **Без ограничений**.
- В шторке уведомлений у Termux нажми **Acquire wakelock** (скрипт делает это сам).
- Не смахивай Termux из списка недавних приложений.

## Как это устроено
Внутри Termux — обычный Linux (Debian). Снаружи телефон доступен через бесплатный туннель Cloudflare;
адрес туннеля иногда меняется — тогда телефон сам обновляет сайт https://jarvis-app-b4p.pages.dev,
и приложение продолжает работать. Память — на телефоне и копией в приватном хранилище Hugging Face.

## Ограничения
- После смены адреса туннеля компьютеры и телефоны, подключённые как «руки» Джарвиса, нужно
  переподключить (веб-приложение и звонок переключаются сами).
- Нужно ~4 ГБ свободной памяти телефона и ~5 ГБ места.
- Доступность адресов Cloudflare из России не гарантирована.

Запуск вручную: `~/jarvis-start.sh`. Журналы: `/opt/jarvis/logs/` внутри Debian
(`proot-distro login debian`).
