# Состояние Джарвиса

**Работает:** полная версия на VPS Рег.ру (6 ГБ) — https://151-248-126-231.sslip.io (Render остановлен),
веб-приложение — https://jarvis-app-b4p.pages.dev (ссылка владельца с ключом — у владельца).
Проверено вживую: звонок из браузера через интернет (сайт → Render), ответ голосом через 3–5 с после фразы.
Память копируется каждые 5 минут в приватный датасет Hugging Face (у Render диск не постоянный).


Ветка `claude/jarvis-cogmem`. Тесты: `pytest -q tests/` (свобода и замок — `tests/test_freedom.py`) (+2 тяжёлых голосовых по флагу `JARVIS_TEST_VOICE=1`).

## Голос с закрытым приложением (Android)
- Фоновая служба `LinkService` живёт, пока телефон включён, и слушает слово «Джарвис» офлайн (Vosk).
  Два этапа проверки, как на ПК. Фраза уходит на сервер, ответ звучит на телефоне.
- Пока Джарвис говорит, микрофон не слушается — он не слышит сам себя.
- **Что может помешать на телефоне:**
  - после перезагрузки служба стартует сама, но Android 14+ может не дать ей микрофон без открытия приложения —
    тогда открой «Джарвис» один раз;
  - производители (Xiaomi, Huawei, Samsung с агрессивной экономией) могут убивать фон — нажми
    «Не выключать в фоне» в приложении;
  - модель голоса (~45 МБ) скачивается при первом запуске — нужен интернет один раз.
- Проверка на реальном телефоне — первое, что стоит сделать.

## Чего ещё нет
- **Живой вызов Claude ни разу не делался** — нет ключа API. Вся логика ИИ проверена на поддельной модели.
  Первое, что стоит сделать с ключом: `python -m evals.behavior -v`.
- **iPhone — только через Команды Siri** (голос, автоматизации). Полное управление экраном требует Mac +
  аккаунт разработчика Apple — отдельный этап.
- **Офлайн-режим** на устройствах (работа без связи с сервером) — отложен по договорённости.
- **Замок на деньги/сообщения** держится на том, что код Джарвиса честно помечает свои действия; произвольный
  обход кодом не распознаётся. Удаление личного на устройствах (по путям: документы, фото, домашняя папка, диск),
  навыки с метками (в т.ч. через другие навыки), чужие устройства заперты жёстко. Удаление в корзину — свободно.
- **Сейф секретов — один на семью** (пароль одного может использоваться в задаче для другого); поэтому траты
  члены семьи (не владелец) могут разрешать только с лимитом и не дольше, чем на сегодня.
- **Мастерская в одном контейнере (HF):** если платформа не даёт ни пространств имён (bubblewrap), ни Landlock
  (ядро < 5.13 или запрещено seccomp), код мастерской может прочитать файлы `/app/data` (база, сейф). Проверка:
  `LocalWorkshop().isolation` → `bwrap` | `landlock` | `none`. Надёжнее всего — отдельный контейнер мастерской
  (`deploy/docker-compose.yml`).
- **Фоновые задачи** живут в памяти процесса: при перезапуске сервера незавершённые теряются.
- **Картинки и PDF от человека** Джарвис видит через орган file (путь приходит в реплике), а не сразу в реплике.
- **Android:** если экран шире 1280 пикселей (планшет), снимок уменьшен, а нажатия — в реальных пикселях;
  пользуйся деревом элементов (координаты в нём реальные).
- **Docker-стек** поднят и проверен (health, веб-приложение, APK, клиент); образы для российского
  ретранслятора и полный прогон с живым Claude в контейнере не делались.
