# Что готово в Джарвисе

Ветка `claude/jarvis-cogmem`. 61 тест проходит (+2 тяжёлых голосовых по флагу `JARVIS_TEST_VOICE=1`).

## Готово и проверено

| Часть | Что умеет | Как проверено |
|---|---|---|
| **Когнитивная память** | помнит всё навсегда, вспоминает по смыслу/словам/связям, забывание по ACT-R, факты с двумя временами, ночной «сон», приватность в семье | стенд 200 дней, 31 вопрос → **100%**; 34 теста инвариантов |
| **Разум, а не команды** | понимает смысл, сам ищет способ, пишет себе навыки (код+тесты), цели, инициатива | тесты цикла, навыков, инициативы; стенд поведения `evals/behavior.py` (нужен ключ) |
| **Свобода и замок** | свободен по умолчанию; деньги/сообщения/удаление/чужие устройства — по ключам от человека | тесты лимитов, одноразовых и отзываемых ключей, защиты от «чужого текста» |
| **Мастерская** | выполняет свой код с интернетом, без доступа к памяти и ключам | проверено в Docker: код идёт, ключа API внутри нет |
| **Устройства** | ПК (Win/Mac/Linux) и Android подключаются по коду, выполняют код, экран, мышь/клавиатура | сквозной тест настоящим клиентом; запуск в Docker |
| **Android-приложение** | полное управление через спец. возможности, фон, голос | собран APK (3.3 МБ), службы и разрешения на месте |
| **Голос** | распознавание GigaAM, синтез Piper, узнавание говорящего — всё локально | круговой тест речи; узнавание на синтезе: свои — да, чужой — нет |
| **Пробуждение «Джарвис»** на ПК | офлайн-слово (Vosk, два этапа) | на синтезе: ловится, без ложных на похожих словах |
| **Каналы** | Telegram (текст+голос), веб-приложение с голосом (PWA), HTTP-API для iPhone (Siri) | веб-приложение проверено в браузере; API — тестами |
| **Семья и Россия** | владелец добавляет родных, ссылки на приложение, ретранслятор в РФ, запасные адреса | тесты; клиент переключается на ретранслятор при блокировке основного |

## Чего ещё нет
- **Живой вызов Claude ни разу не делался** — нет ключа API. Вся логика ИИ проверена на поддельной модели.
  Первое, что стоит сделать с ключом: `python -m evals.behavior -v`.
- **iPhone — только через Команды Siri** (голос, автоматизации). Полное управление экраном требует Mac +
  аккаунт разработчика Apple — отдельный этап.
- **Офлайн-режим** на устройствах (работа без связи с сервером) — отложен по договорённости.
- **Замок на деньги/сообщения** держится на том, что код Джарвиса честно помечает свои действия; произвольный
  обход кодом не распознаётся. Удаление, навыки с метками, чужие устройства заперты жёстко.
- **Сейф секретов — один на семью** (пароль одного может использоваться в задаче для другого).
- **Docker-стек** поднят и проверен (health, веб-приложение, APK, клиент); образы для российского
  ретранслятора и полный прогон с живым Claude в контейнере не делались.

## Что нужно от тебя
Ключ Claude API, VPS во Франции + домен, по желанию — дешёвый VPS в России для ретранслятора.
Пошаговая установка — в `docs/setup.md`.
