# Как запустить Джарвиса — по шагам

Время: около часа. Нужно: карта для оплаты сервера и Claude API, телефон, компьютер.

## 1. Ключ Claude API
1. Зайди на console.anthropic.com → зарегистрируйся → Billing: пополни на $20–40.
2. API Keys → Create Key → скопируй строку `sk-ant-…`. Это пароль: никому не показывай.

## 2. Сервер (VPS во Франции)
1. Арендуй VPS: Ubuntu 24.04, **4 ГБ памяти минимум (лучше 8)**, 40 ГБ диска. Например, Hetzner CX32 или
   Scaleway — около 8–10 € в месяц.
2. Купи домен (около 10 €/год, например на OVH или Namecheap) и сделай A-запись `jarvis.твой-домен` → IP сервера.
3. Зайди на сервер (ssh root@IP) и выполни:
   ```bash
   curl -fsSL https://get.docker.com | sh
   git clone https://github.com/lilcryyw/Agent.git jarvis && cd jarvis
   git checkout claude/jarvis-cogmem
   cp .env.example .env && nano .env
   ```
4. В `.env` заполни: `ANTHROPIC_API_KEY`, `JARVIS_OWNER_NAME`, `JARVIS_DOMAIN`, `JARVIS_WORKSHOP_TOKEN`
   (любая длинная строка), по желанию — Telegram (шаг 3).
5. Запусти: `cd deploy && docker compose --env-file ../.env up -d --build`. Первый запуск — 10–20 минут (скачиваются модели
   речи и смысла, ~3 ГБ). Проверка: открой `https://jarvis.твой-домен` — должно быть «Джарвис на связи».

## 3. Telegram (удобно для начала)
1. В Telegram найди @BotFather → `/newbot` → имя → получишь токен → впиши в `.env` как `TELEGRAM_BOT_TOKEN`.
2. Узнай свой числовой id у @userinfobot → впиши `JARVIS_TELEGRAM_USERS=твой_id:owner`.
3. `docker compose --env-file ../.env up -d` ещё раз. Напиши боту «привет».

## 4. Голос на телефоне
- **Любой телефон**: попроси Джарвиса «дай мне ссылку на приложение» → открой ссылку → «На экран Домой».
  Дальше — большая кнопка микрофона.
- **iPhone с Siri**: команда `/token` в Telegram → инструкция в [docs/iphone.md](iphone.md).

## 5. Компьютер
Скажи Джарвису: «подключи мой компьютер» — он выдаст код и 3–4 команды. Выполни их — и он сможет
работать на ПК: открывать программы, ставить приложения, смотреть экран, отвечать на «Джарвис, …» голосом.

## 6. Родные
Скажи: «добавь маму, Ольга Петровна, она в Самаре» → «дай ссылку для мамы». Отправь ей ссылку любым способом.
Если в России ссылка не открывается — нужен ретранслятор:
1. Арендуй маленький VPS в России (Timeweb/Selectel, ~300 ₽/мес), домен `ru.jarvis.твой-домен` → его IP.
2. На нём: `curl -fsSL https://get.docker.com | sh`, скопируй папку `deploy/relay`, затем
   `RELAY_DOMAIN=ru.jarvis.твой-домен JARVIS_DOMAIN=jarvis.твой-домен docker compose up -d`.
3. На основном сервере в `.env`: `JARVIS_RELAY_DOMAIN=ru.jarvis.твой-домен` и `docker compose --env-file ../.env up -d`.
   Теперь Джарвис сам даёт и запасную ссылку.

## Пароли и разрешения
- Пароль, которым Джарвис должен пользоваться: `/secret имя значение` в Telegram (сообщение удалится).
- Деньги, сообщения от твоего имени, удаление данных — только с ключом: скажи, например,
  «можешь сам заказывать продукты до 50 евро». «Покажи ключи», «забери все ключи» — тоже голосом.
- «Джарвис, стоп» — остановить. Бюджет на ИИ в месяц — `JARVIS_MONTHLY_BUDGET_USD` в `.env`.

## Резервная копия
Вся память, навыки и сейф — в папке `data/` на сервере. Раз в неделю копируй её
(например, `tar czf backup.tgz data` и скачать себе).

## Если что-то не так
- `docker compose logs -f jarvis` — что происходит.
- Проверка памяти без затрат: `docker compose exec jarvis python -m evals.run --hash`.
